## Decisões da sessão que não se derivam do código

- **O kit do Figma é imagem, não objetos de desenho** (informação do Rafael em 18/09). Isso matou de vez
  a ideia de ler tokens pela API: as quatro pendências saíram por **amostragem de pixel**
  (`tools/amostragem-do-kit.py`, versionada). A pendência dos ícones em vetor foi **encerrada** — não há
  vetor a exportar em lugar nenhum, e o Tabler (ADR-005) deixou de ser interino.
- **As sombras do kit se sobrepõem na grade** (quadrados de 71 px com 25 px de folga): medir uma a uma
  inventava "spread" de 20 px que não existe. O ajuste é conjunto, cada quadrado sobre o resíduo dos
  outros. A sombra **não é preta** — escurece menos o azul.
- **O roxo dos fundos suaves era `#9155FD` a 12%**, cor que não existe na paleta do kit (primary é
  `#264CC8`): resquício do template de origem. Decisão do Rafael: **harmonizar** (`#E5EAF8` no claro,
  `#30315B` no escuro).
- **Texto desabilitado passou de 0,38 para 0,26** nos dois temas (é o que o kit mostra). WCAG isenta
  componente desabilitado do contraste mínimo (1.4.3).
- **`.xlsx` leva número, não texto formatado** — o CSV existe para ler, a planilha para somar.
- **Animação de gráfico é CSS puro, nunca estado inicial no C#**: barra "nascendo em zero" pelo segundo
  render deixaria o gráfico vazio em SSR estático, onde `OnAfterRender` não roda.
- **Entrada de 1 s para todos os tipos**, num token só (`--rvm-grafico-entrada` em `.rvm-grafico`, que o
  consumidor pode sobrescrever). A transição de **mudança de valor** ficou em 250 ms de propósito: ela
  responde a um clique, e 1 s pareceria travamento.
- Direção de cada entrada (corrigida depois de o Rafael ver no dev): colunas e histograma **crescem do
  eixo para cima**; barras abrem da esquerda; linha, área e **dispersão** saem da origem (0,0); rosca é
  uma **varredura de relógio** do meio-dia; **só o radar** cresce do centro.

## Armadilhas descobertas (valem para as próximas sessões)

1. **`bash esteira.sh | tail -20` devolve o exit code do `tail`.** A esteira do PR #61 morreu numa falha
   de rede antes do merge e a notificação disse "exit code 0"; só o estado do PR revelou. Script de
   esteira roda **sem pipe** e com `set -eo pipefail` (já corrigido nos scripts desta sessão).
2. **Teste de arquivo binário tem de abrir o conteúdo.** O E2E do `.xlsx` só conferia a assinatura `PK`
   e passava verde com a planilha corrompida (valor `NaN`/infinito ou caractere de controle no XML).
   Hoje há teste que valida o XML de **todas** as partes do pacote com `XmlDocument`.
3. **O Playwright casa nome acessível por substring.** Um exemplo novo chamado "Area e produtividade por
   talhao" fez `getByRole('group', { name: 'Produtividade por talhao' })` casar com dois elementos e
   quebrar um teste antigo.
4. **`var(--token-que-não-existe)` não pinta nada e nenhum teste reclama.** O véu da faixa selecionada
   ficou invisível por usar `--rvm-primary` (o token é `--rvm-color-primary-text`). Só apareceu na foto.
5. **A roda do mouse não para a página pelo `@onwheel`**: o Blazor registra os ouvintes dele como
   passivos. Ouvinte de `wheel` que precisa cancelar a rolagem vai no módulo JS com `{ passive: false }`.
